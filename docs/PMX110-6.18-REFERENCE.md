# Referensi Firmware OPPO PMX110 (MediaTek 6.18)

Dump: `rama-firmware-dumps/oppo/PMX110`, branch
`sys_mssi_64_cn_armv82-user-17-CP2A.260605.016-1789749211753-release-keys`
(Android 17, MediaTek 6.18).

Diambil 2026-11-23 dari `all_files.txt` dan beberapa `.ko` untuk referensi
porting X6871 ke 6.18. Ini **bukan** sumber kode dan tidak dipakai langsung
dalam build.

## Clock platform: in-tree vs OOT

`vendor_boot/ramdisk/lib/modules/clk-common.ko` mengekspor:

```text
mtk_alloc_clk_data
mtk_free_clk_data
mtk_clk_register_fixed_clks
mtk_clk_register_factors
mtk_clk_register_gates
mtk_clk_register_composites
mtk_clk_register_dividers
mtk_clk_register_gate
mtk_clk_register_gate_hwv
mtk_clk_register_plls
mtk_clk_register_muxes
mtk_clk_simple_probe
...
```

`clk-mt6995.ko` bergantung pada `clk-common` dan mengimpor
`mtk_alloc_clk_data`, `mtk_clk_register_plls`, `mtk_clk_register_muxes`, dll.

**Implikasi X6871:** `CONFIG_COMMON_CLK_MEDIATEK` in-tree memang tidak
dipakai. OOT `clk-common.ko` (dari `kernel_device_modules-6.18`) adalah
penyedia simbolnya, sama seperti yang sudah diterapkan di `X6871.config`.

## Tambahan untuk codemod X6871

Selain 8 kelas di `scripts/port-6.18-mechanical.py`, referensi ini
menunjukkan transformasi yang perlu ditambahkan/diperiksa:

1. `init_dummy_netdev(...)` → `alloc_netdev_dummy(...)`.
2. `netif_napi_add_weight(...)` → `netif_napi_add_weight_locked(...)`.
3. `__netif_napi_del(...)` → `__netif_napi_del_locked(...)`.
4. `napi_gro_flush`/`napi_gro_receive` → `__gro_flush`/`gro_receive_skb`
   (cek per call site; bukan rename buta).
5. `crypto_shash_update` + `crypto_shash_final` → `crypto_shash_finup`
   atau `crypto_shash_digest`.
6. `tracepoint_srcu`/iterasi tracepoint lama →
   `for_each_kernel_tracepoint` + `tracepoint_probe_register/unregister`.
7. `iommu_present(dev)` → `iommu_get_domain_for_dev(dev)` (sesuaikan
   semantik, bukan rename buta).
8. `__SetPageMovable`/`__ClearPageMovable` → folio API atau
   nonaktifkan `CONFIG_MALI_PAGE_MIGRATION` lebih dulu.
